# oryzoaicopybest3d

Educational 1:1 study clone of [oryzo.ai](https://oryzo.ai) — a mirror of the site's deployed static build, made to study how its Three.js scenes, GSAP/ScrollTrigger/SplitText animations, and scroll choreography work.

**All design, copy, images, video, and code belong to Oryzo.** This repo exists purely for learning purposes and is not affiliated with, endorsed by, or intended to impersonate Oryzo.

## Status

- [x] Stage 1 — Reference frames extracted from screen recording (local only, not committed)
- [ ] Stage 2 — Repo scaffold
- [ ] Stage 3 — Mirror core files (HTML / CSS / JS)
- [ ] Stage 4 — Harvest all assets (images / video / fonts / 3D)
- [ ] Stage 5 — Local verification against reference frames
- [ ] Stage 6 — Final polish

## Run

```bash
npx serve .
```

Then open the printed localhost URL.
